# 店舗情報 検索システム

検索窓に1つ入れる（店舗番号・店舗名・振込名義・配達者名・商品名 など）と、
該当する店の情報がカードで出る検索システムです。

## ローカルで動かす（まずはこれ）

同じフォルダに `店舗.csv` と `商品.csv` があれば、そのまま動きます。

```bash
streamlit run app.py
```

ブラウザが開いたら、検索窓に `113` や `肉まん` と入れて試してください。

## 本番（Googleスプレッドシート＋Streamlit Cloud）

1. スプレッドシート「店舗台帳」を用意（タブ名：`店舗` と `商品`、列は上の説明どおり）
2. サービスアカウントを作り、その鍵を用意
3. スプレッドシートを、サービスアカウントのメールアドレスに「閲覧者」で共有
4. GitHub にこのフォルダを上げる（`secrets.toml` は上げない）
5. Streamlit Cloud でアプリを作り、Secrets に鍵を貼り付ける

※ 設定が無ければ自動でローカルCSVを読むので、ローカルと本番で同じ `app.py` が使えます。

## 表示の切り替え（ヒット数で自動）

- 3件以下 … 大きいカードで詳しく表示
- 4件以上 … 小さいタイルを並べて一覧で表示（数百件でも見やすい）

この境目は `app.py` の `BIG_CARD_LIMIT = 3` の数字を変えれば調整できます。

## ファイルの説明

- `app.py` … アプリ本体
- `店舗.csv` / `商品.csv` … ローカル開発用のサンプルデータ
- `requirements.txt` … 本番で自動的に入るライブラリ一覧
- `.streamlit/config.toml` … 画面全体の色（デザイン設定）
- `.streamlit/secrets.toml.example` … 本番の鍵を入れる形の見本
- `.gitignore` … 秘密情報をGitHubに上げないための設定
